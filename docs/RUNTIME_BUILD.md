# Runtime build entry point

The canonical build/runbook is [RUNTIME](RUNTIME.md): separate Wine engine
production, persistent-engine fetch, wrapper/winetricks assembly, manifests,
checksums, provenance/SBOM and validation limits.

[RELEASE](RELEASE.md) owns signing/storage/registration and [TESTING](TESTING.md)
owns the check matrix. [STATUS](STATUS.md) owns dated results.
This path is retained for older links; the duplicated recipe and operational
claims were consolidated.
