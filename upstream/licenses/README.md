# Upstream license inventory

License and copyright files remain in each imported snapshot under `vendor/`.
This directory records the inventory boundary rather than copying or
rewriting upstream legal text. Before production promotion, update
`RUNTIME_LICENSES.md` and `THIRD_PARTY_NOTICES.md` with the exact notices for
the generated artifact and its transitive dependencies.

The project-provided authorization statement is recorded in
`SIKARUGIR_AUTHORIZATION.md`. The authoritative signed authorization, if
provided separately, must be attached by the repository owner during legal
review; it is not embedded here or inferred from a repository URL.
